# Learn Java GUI

A comprehensive, project-based repository for learning professional Java desktop application development using **JavaFX**, **Scene Builder**, **JDBC**, and **MVC architecture**.

This repository is designed for developers who want to focus on **software engineering**, **clean architecture**, and **backend logic** rather than spending excessive time designing user interfaces manually.

Instead of isolated tutorials, every concept is introduced through practical projects that gradually increase in complexity, allowing you to build real desktop applications while learning industry-standard development practices.

---

## Objectives

* Learn modern Java desktop application development.
* Understand JavaFX architecture and the Java UI lifecycle.
* Build professional desktop applications using Scene Builder.
* Practice clean code and maintainable project structures.
* Apply MVC architecture in real applications.
* Integrate relational databases using JDBC.
* Learn reusable UI components and controller design.
* Build a portfolio of complete desktop applications.
* Develop software engineering skills through project-based learning.

# Learning Philosophy

This repository follows a **project-first** approach.

Instead of learning dozens of UI components independently, each project introduces only the concepts required to complete it.

Every new project builds upon the previous one while introducing new topics such as layouts, events, database connectivity, MVC, reusable components, and application architecture.

The primary goal is to become capable of building complete desktop software rather than simply learning GUI widgets.

---

# MVC Architecture

```text
User

↓

FXML View

↓

Controller

↓

Service

↓

DAO

↓

Database
```

Each layer has a single responsibility.

* **View** → Displays the interface.
* **Controller** → Handles user interaction.
* **Service** → Contains business logic.
* **DAO** → Manages database operations.
* **Model** → Represents application data.
